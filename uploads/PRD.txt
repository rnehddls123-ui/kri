목차



1. 제품 개요
1.1 한 줄 정의
도쿄를 처음 방문하거나 일정 짜기 귀찮은 사람을 위한, 취향 기반 도쿄 여행 일정 생성 서비스.
1.2 문제 정의
도쿄 여행을 준비하는 사람은 두 가지 벽에 부딪힌다. 정보가 너무 많아 어디서 시작할지 모르거나, 정보를 알아도 동선을 직접 짜는 게 번거롭다. 기존 여행 앱은 장소 리스트만 던져줄 뿐, 사용자 취향에 맞춰 하루를 설계해주지 않는다.
1.3 솔루션
14개 미만의 가벼운 질문으로 사용자 취향을 파악하고, 이를 기반으로 취향 캐릭터를 생성한 뒤 완성된 동선(지도 + 타임라인)을 제공한다. 단순 일정 생성기가 아니라 &apos;도시 감정 큐레이터&apos;를 지향한다.

4. 핵심 기능
4.1 취향 캐릭터 생성
입력값을 기반으로 사용자를 대표하는 캐릭터 1개를 생성한다. 네이밍 구조는 &apos;[지역]에서 [메인 카테 기반 행동]하는 [서브 카테 기반 형용사]&apos; 형식이다.
예시: 우에노에서 먹방 찍는 쇼핑 중독자 / 시모키타자와에서 레코드 고르는 카페인 중독자
사용자가 남/녀를 선택하면 캐릭터명 기반으로 고정 스타일(3D 클레이) 이미지를 1회 생성한다.
4.2 동선 생성
공항 도착부터 숙소 체크인, 권역 이동, 장소 방문, 숙소 복귀까지 하루 전체의 물리적 흐름을 9단계 알고리즘으로 구성한다. 메인 카테고리 노드를 전체의 50% 이상 배치하고, 서브 카테고리를 1~2개 섞는다.
숙소가 여러 곳인 경우 체류 일자에 맞춰 권역 기준점을 전환하며, 숙소 변경일은 짐 이동을 고려해 노드 1개를 감산한다.
4.3 결과 출력
상단: 캐릭터 프로필 + 출입국 항공편 요약
중단: 지도 동선 시각화
하단: 일자별 타임라인 (시간 / 장소 / 이동정보 / 큐레이션 설명)
장소 상세: 팩트 정보 3줄 + 추천 이유 2줄 + 구글맵 링크
